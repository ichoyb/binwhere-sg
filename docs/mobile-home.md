# App 地图首页、搜索、关于、相机与答案

首页、答案和飞行始终共用 `MapHomeScreen` 中的一个 MapLibre 实例。地图使用包内素材，不依赖网络加载底图。地图样式、点色、数据源与相机接口见 [地图模块](map-rendering.md)。相机、定格照片和答案卡是地图之上的 React Native 层；打开和关闭这些层不会重新创建地图。

## 点位数据

`mobile/src/api/client.ts` 的 `fetchPoints` 请求 `/api/v2/points`，成功响应用 `PointsResponseSchema` 解析，错误响应用 `ApiV2ErrorResponseSchema` 解析。不能解析的响应通过现有 contract violation 链路上报。

AsyncStorage 的 `binwhere.points.v2` 保存上次成功响应、ETag 和完整接口地址。读取时重新解析响应；损坏的记录删除，地址不同的记录不使用。启动先显示缓存，再带 `If-None-Match` 请求校验：304 保留当前数据，200 替换数据并写缓存。校验失败（包括 429）保留已有缓存；没有成功数据时只显示底图，给出失败提示和重试入口。不会自动循环重试。

点位仅用于地图展示和详情。答案的最近去处由 `/api/v1/nearby` 决定，先查 1 km，结果为空才查 5 km。

## 首页交互

五种图层默认全开。BCRS 胶囊打开指南，并将首页图层切换为只显示 BCRS，关闭答案后保持这个选择。搜索面板里的指南入口只在答案期间显示 BCRS，关闭后恢复此前的首页图层。

全岛点按以点击位置为中心每次放大两级，达到 zoom 14 后点按点位才打开详情。详情展示类型、名称及非空地址；电子废物点在接口提供接收种类时，在地址下面展示本地化的接收种类，接口未提供时不显示该行；尚未取得路线时，位置在新加坡则显示球面距离并标明“直线”。每张卡片有“步行路线”按钮，按定位按钮相同的权限及新加坡范围规则获取位置，再请求路线。定位被拒、取不到或在境外时显示已有位置提示，不请求路线。路线成功后平移和缩放地图保留卡片和路线；尚未取得路线或请求失败时，手动移动地图仍关闭详情。地图空白处点按、选择另一点、打开搜索或相机时清除路线、气泡和目的地。

定位按钮按需申请前台权限，已经授权的启动只读取一次位置。启动读取位置失败时不设置错误或上报；查询权限本身异常才上报。主动定位时，仅在位置处于新加坡边界内时飞到 zoom 16；权限被拒、读取失败或身处境外会显示原因，不移动相机。用户位置使用无文字图标。系统开启减弱动态效果时，相机通过地图模块的 `jumpTo` 移动；系统设置变化会实时更新。

OSM 署名首次以 14 号小字显示“© OpenStreetMap”，五秒或第一次手动移动地图后收成小 ⓘ。这是 OSMF 署名指南对交互地图允许的最小做法，改动时不能再弱化。24 高的深色承载面帮助文字在海面和街区上保持清晰；`hitSlop` 将命中区扩到至少 52×52，父行预留完整命中空间。两种状态都用系统浏览器打开 core 的 `DATA_LICENSE_URL`。首页署名位于底部控件上方，答案地图上的署名位于左上角，均不与卡片重叠。

底部搜索栏打开深色搜索面板并聚焦输入框。关闭系统“减少动态效果”时，面板从底部升起；开启时直接到位，输入框同样获得焦点并弹出键盘。打开期间隐藏首页控件，地图实例和图层选择保留；关闭按钮或在面板顶部向下轻扫收起面板，不移动地图。相机按钮直接打开全屏相机。

## 搜索面板

`SearchPanel` 是地图之上的独立组件，通过 React Native 的 `Animated`、`PanResponder` 和 `Keyboard` 处理升起、顶部下滑关闭及键盘空间。动画沿用共享地图已经读取的“减少动态效果”设置：开启时开合与未过关闭阈值的复位均直接完成，关闭时保留滑动与回弹。面板上方保留地图与署名，输入区固定在面板顶部，其余内容可滚动。

输入时，本地分类建议按去除首尾空白、不区分大小写的子串匹配。当前语言不是英文时，同时匹配同一物品的英文名。以输入开头的结果优先，其余保持分类数据顺序；显示当前语言的物品名和所属分类。分类翻译按分类 ID 与英文物品名覆盖，保留顺序；没有对应翻译时沿用英文。建议直接打开分类中写好的答案，不请求识别接口，离线也可用。

键盘搜索键和搜索按钮都提交去除首尾空白的文字，最大长度为 `MAX_CLASSIFY_TEXT_LENGTH`。空输入和识别期间禁用提交；开始时只读取已经授权的定位。失败时在输入框附近显示友好错误，保留文字，成功后才清空。关闭面板会中止请求，晚到的结果不显示、不写入历史。

没有输入时，面板依次显示非空历史、BCRS 指南、可展开的分类浏览及底部的语言和关于入口。历史物品以状态色标记，清除按钮立即清空。四种语言可直接选择，切换立即作用于整个 App 并持久保存，面板保持打开。这是 App 内的语言入口。

文字、建议、分类、历史、BCRS 指南和拍照结果都使用同一个答案组件；交出答案时面板立即消失。历史保存完整结果，不保存照片。识别、建议和分类写入历史，重开历史及 BCRS 指南不新增记录。

## 关于

`AboutScreen` 从搜索面板底部进入，入口使用 `›` 表示应用内页面，以独立全屏页覆盖地图，关闭后回到仍然打开的面板。版本号和构建号从 `expo-application` 的 `nativeApplicationVersion` 与 `nativeBuildVersion` 读取，构建号不从 JS 配置推断。

页面包含独立项目与无隶属或背书关系的声明、各类回收点的数据发布方，以及地图、树木、步行路线的“© OpenStreetMap contributors”和 ODbL 署名。数据许可链接使用 core 的 `DATA_LICENSE_URL`，不展示数据更新日期。

AI 说明告知照片或文字发送至腾讯云，处理可能在新加坡以外进行，腾讯云最多保留 30 天并做内容审核。页面最后以“隐私与帮助”为节标题，提供隐私政策、支持及可选中复制的联系邮箱；邮箱行以次要文字显示“联系邮箱”标签。外链由系统浏览器或邮件 App 打开，打开失败通过 `reportError` 上报。

## 相机与识别

全屏相机提供关闭按钮，只在相机已授权并启动时显示 72 大小的快门，不放取景文字或相册占位。首次进入相机时申请系统权限。永久拒绝时说明原因，并提示关闭相机、改用首页搜索栏输入物品；关闭按钮返回首页。

拍照后使用原照片铺满屏幕，并通过 `prepareImageForClassify` 压缩上传。快门换为绿色进度环，识别期间不显示文字。进度为 `0.94 × (1 − exp(−elapsedMs / 3500))`，先快后慢且不达到 1；答案到达时卡片立刻出现，盖住进度环。已经授权定位时，识别开始同时读取位置，不申请新权限。

取消会中止 `AbortController`，回到取景；即使结果晚到，也不会显示或写入历史。失败时保留照片，沿用友好错误文案；“重试”重新发送同一张照片，“回到取景”清除照片。

## 答案与去处

答案到达立即显示玻璃卡片。收起时显示类型、物品名和最重要的一句：优先使用 `next_action.title`，其次是 `instruction.<channel>`，没有 channel 时显示原因。找到目标后，收起时也显示名称、非空地址和开放时间，以及距离；路线尚未取得时标明“直线”。

有 `next_action` 时，展开后显示动作说明与资格，标题沿用卡片主句，不重复显示，也不显示原因、去处说明、准备步骤或提示。没有 `next_action` 时，展开后可阅读低置信度提示、原因、去处说明、准备步骤和提示。BCRS 展示退还金额、四个步骤、适用及不适用范围和回收点数量；有害垃圾提供可拨打的热线。分享使用 `getResultShareText`。无内容的字段不占空行。

去处规则仅依据 mobile 的 channel 规则，Web 的规则不变：

| 答案 | 查找方式 | 附近类别 | 答案期间的点位图层 |
| --- | --- | --- | --- |
| BCRS | 自动 | return_point | return_point |
| 电子废物 | 自动 | ewaste | 无 |
| 电池 | 自动 | ewaste_battery | 无 |
| 灯管 | 自动 | lighting | 无 |
| 旧衣 | 自动 | textile | textile |
| 捐赠 | 自动，按物品映射筛选 | donation | 有物品筛选时无；无筛选时 donation |
| 大件垃圾 | 自动，Furniture 筛选，去处区域标明“考虑捐赠” | donation | 无 |
| 蓝色回收桶 | 点击“附近的蓝色回收桶” | blue_bin | 点击后 blue_bin |
| 不确定容器（check_container_type） | 点击“查找附近退还点” | return_point | 点击后 return_point |
| 一般垃圾、有害垃圾、其余空 channel | 保留照片或当前地图 | 不查询 | 保持首页选择 |

大件垃圾的去处区域在查找中、找到目标、附近没有及查询失败时，都以“考虑捐赠”标明这些是收家具的捐赠点。

需要去处时才申请尚未授权的定位。定位被拒、取不到或位于新加坡以外时，不查询 nearby，显示全岛与对应原因。5 km 内无目标时同样显示全岛和说明。只有能完全对应的点位图层会亮起，电子废物、电池、灯管及有物品筛选的捐赠不使用整层代替。查询失败显示说明及手动重试。

有照片时，照片通过 native driver 缩小、淡出约 700 ms，露出全岛，再用约 3 s 飞入目标的 3D 街区；没有照片时直接从当前视角飞往目标。落点至少 zoom 14、倾角 55°，卡片上方留出目标空间；能在街区视角内同时容纳用户和目标时展示两者，否则优先目标。减弱动态效果时不缩放照片、不飞行，直接切到落点，目的地脉冲保持静止。

“关闭”清除路线、距离气泡、目的地及答案图层覆盖，恢复此前的首页图层选择，地图保留当前位置。“再扫一个”同样清除地图中的答案数据，再直接打开相机。

## 步行路线

答案找到去处后立即请求 `POST /api/v2/route`，与相机飞行并行。原生地图通知飞行结束后显示发光路线及长度中点的距离气泡；路线晚到时等待响应，减弱动态效果时等待相机直接切到落点。路线使用接口原几何，地图不补画吸附点与用户或目标之间的空隙。

首页点位卡片和答案共用路线信息：成功后距离改为步行距离、约分钟数及步行单位，分钟向上取整且至少为 1。终点吸附距离超过 15 m 时说明路线到目标附近为止，最后一段需看现场指示。VoiceOver 可读取步行距离、时间及说明。卡片增加说明、重试或展开后，按实际布局高度重新取景，预留卡片上方的目标空间；首页使用整个底部控件的实测高度。

每个目标自动请求一次，只在用户点“重试”时再次请求。路线不可用时清除线和气泡，保留注明“直线”的距离。50 m 内无可步行路网或找不到路线时说明原因，不提供重试；限流与网络失败使用已有错误文案并允许重试；服务忙、服务不可用、超时或响应违约时显示暂时无法生成路线并允许重试。权限或输入错误同样允许重试，并只上报错误码与 HTTP 状态。切换目标或离开当前结果会取消请求，晚到结果不再显示。

路线请求在客户端边界用 `RouteRequestSchema` 校验，成功及错误响应分别用 v2 schema 解析。请求、响应、服务端错误文字与动态 schema 路径不进入错误消息、上报 context 或契约违例 issues；路线 URL 没有坐标查询参数。网络失败在 mobile 单独表示，不扩展 core 错误契约。

## 深色组件

`mobile/src/theme/dark.ts` 定义深色背景、烟熏玻璃底色和边框、正文和次要文字、绿色强调色和其上的深色内容，以及字号、控件尺寸、圆角和间距。搜索面板与关于页也使用这组 token 和玻璃组件。`colors.ts` 仅保留错误边界和启动加载视图仍在使用的 token；启动配置、加载视图和错误边界各自沿用既有外观。

`GlassPanel` 结合 Expo Blur 和深色覆盖层提供玻璃容器，`GlassButton` 提供带无障碍标签、选中状态和最小 52 高度的玻璃按钮。相机按钮为 72，正文为 16，说明文字为 14。玻璃底色覆盖率为 88%，最亮底图上也保持深色承载面。
