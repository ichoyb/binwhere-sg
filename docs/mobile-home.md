# App 地图首页、搜索、关于、相机与答案

首页、答案和飞行始终共用 `MapHomeScreen` 中的一个 MapLibre 实例。地图使用包内素材，不依赖网络加载底图。地图样式、点色、数据源与相机接口见 [地图模块](map-rendering.md)。相机、定格照片和答案卡是地图之上的 React Native 层；打开和关闭这些层不会重新创建地图。

## 点位数据

`mobile/src/api/client.ts` 的 `fetchPoints` 请求 `/api/v2/points`，成功响应用 `PointsResponseSchema` 解析，非 429 的错误响应用 `ApiV2ErrorResponseSchema` 解析。不能解析的响应通过现有 contract violation 链路上报。四个接口的 HTTP 429 都直接作为限流，不解析正文，也不上报契约违约。

AsyncStorage 的 `binwhere.points.v2` 保存上次成功响应、ETag 和完整接口地址。读取时重新解析响应；损坏的记录删除，地址不同的记录不使用。启动先显示缓存，再带 `If-None-Match` 请求校验：304 保留当前数据，200 替换数据并写缓存。校验失败（包括 429）保留已有缓存；没有成功数据时只显示底图，给出失败提示和重试入口。不会自动循环重试。

点位仅用于地图展示和详情。答案的最近去处由 `/api/v1/nearby` 决定，先查 1 km，结果为空才查 5 km。

## 首页交互

五种图层默认全开。BCRS 胶囊打开指南，并将首页图层切换为只显示 BCRS，关闭答案后保持这个选择。搜索面板里的指南入口只在答案期间显示 BCRS，关闭后恢复此前的首页图层。 图层面板底边与底部控件保持间隔，文字和开关不会被底栏覆盖；溢出的内容在面板内滚动。

全岛点按以点击位置为中心每次放大两级，达到 zoom 14 后点按点位才打开详情。详情展示类型、名称及非空地址；电子废物点在接口提供接收种类时，在地址下面展示本地化的接收种类，接口未提供时不显示该行；尚未取得路线时，按设备位置或手动地区中心显示球面距离并标明“直线”；手动来源在距离上方标明“起点：某地中心”。每张卡片有“步行路线”按钮，从统一的位置来源获取起点，再请求路线。定位被拒、取不到或在境外时显示已有位置提示，不请求路线。路线成功后平移和缩放地图保留卡片和路线；尚未取得路线或请求失败时，手动移动地图仍关闭详情。地图空白处点按、选择另一点、打开搜索或相机时清除路线、气泡和目的地。

设备来源下，定位按钮按需申请前台权限，启动在存储读取完成后只读取已经授权的位置。启动读取位置失败时不显示提示；查询权限本身异常上报。主动定位在新加坡境内时飞到 zoom 16、pitch 55、bearing 0；位置图标没有文字。手动来源下直接飞到地区中心，隐藏设备位置图标，底部提示“以某地为中心”，提供“更换地区”和“改用我的位置”；后者立即切回设备定位。系统开启减弱动态效果时，相机通过地图模块的 `jumpTo` 移动；系统设置变化会实时更新。

地图先呈现倾角 50° 的全岛视图。地图就绪且本次启动第一次有可用位置时（两者以后到的为准），只判断一次：搜索面板、相机和答案都未打开，并且用户尚未手动移动地图时，约 2 秒飞到与定位按钮相同的街区落点。可用位置是设备来源下已经授权且在新加坡境内的位置，或手动来源的地区中心。判断时首页不可见或地图已经被手动移动，本次启动就放弃自动飞行；飞过后也不再自动移动。未授权、取不到位置或境外位置保留全岛，不在启动时申请新权限。减弱动态效果时直接 `jumpTo` 街区，没有飞行；飞行中的地图触碰沿用 MapLibre 的默认中断行为。

### 位置来源与不可用提示

AppState 统一提供设备位置或手动地区中心。`location` 只保存设备位置；手动地区不申请定位权限、不读取设备位置，也不在识别开始时预热定位。手动地区以 `{ code }` 保存在 AsyncStorage 的 `binwhere.location-area.v1`，与语言和历史一起读取后才就绪；切回设备来源删除此值。坏 JSON、结构错误或未知地区会删除并上报，读取异常也上报，均按设备来源就绪。写入和删除失败上报，当前来源仍切换。

答案去处、首页定位和点位步行路线共用失败原因与按钮：拒绝定位显示“打开设置”和“选择新加坡地区”；取不到位置显示“重试”和地区选择；境外位置只显示地区选择。提示文字沿用原文，首页仍可关闭提示。“打开设置”调用系统设置入口，失败上报。回到前台重新读取权限，允许后拒绝提示消失；答案卡仅在正显示拒绝提示且没有进行中的请求时自动重新找去处，首页与点位卡不自动重试。

地区选择为全屏玻璃面板，32 个地区始终按英文名排序，显示当前语言名称，名称不同于英文时附英文小字。行高至少 52；面板为无障碍模态，打开后 VoiceOver 聚焦标题。关闭保留来源与原提示；选择后进入手动来源并继续原操作。手动来源一直保持到“改用我的位置”，重启也保留。每次操作记录来源和地区，来源改变后旧结果不显示、不上报。

OSM 署名首次以 14 号小字显示“© OpenStreetMap”，五秒或第一次手动移动地图后收成小 ⓘ。这是 OSMF 署名指南对交互地图允许的最小做法，改动时不能再弱化。24 高的深色承载面帮助文字在海面和街区上保持清晰；`hitSlop` 将命中区扩到至少 52×52，父行预留完整命中空间。两种状态都在 App 内打开 core 的 `DATA_LICENSE_URL`。首页署名位于底部控件上方，搜索面板和答案地图上的署名位于左上角，均不与卡片重叠。搜索面板打开且关于页关闭时，署名入口位于面板层之上，可以点开；面板上方地图仍不接收拖动和缩放。

底部搜索栏打开深色搜索面板并聚焦输入框。关闭系统“减少动态效果”时，面板从底部升起；开启时直接到位，输入框同样获得焦点并弹出键盘。打开期间隐藏首页控件，地图实例和图层选择保留；关闭按钮或在面板顶部向下轻扫收起面板，不移动地图。相机按钮直接打开全屏相机。

## 搜索面板

`SearchPanel` 是地图之上的独立组件，通过 React Native 的 `Animated`、`PanResponder` 和 `Keyboard` 处理升起、顶部下滑关闭及键盘空间。动画沿用共享地图已经读取的“减少动态效果”设置：开启时开合与未过关闭阈值的复位均直接完成，关闭时保留滑动与回弹。面板上方保留地图与署名，默认字号下输入区固定在面板顶部，其余内容可滚动；放大字号时整块内容可滚动，给输入、按钮与正文留出完整显示空间。

输入框使用 App 专用的 `search.placeholder`；英文、中文和马来文沿用首页示例，泰米尔文只显示“எ.கா. பிளாஸ்டிக் பாட்டில்”。

输入时，本地分类建议按去除首尾空白、不区分大小写的子串匹配。当前语言不是英文时，同时匹配同一物品的英文名。以输入开头的结果优先，其余保持分类数据顺序；显示当前语言的物品名和所属分类。分类翻译按分类 ID 与英文物品名覆盖，保留顺序；没有对应翻译时沿用英文。建议直接打开分类中写好的答案，不请求识别接口，离线也可用。

输入框允许长文字随宽度换行，最高占屏幕高度的 20%，超出后在框内滚动；粘贴或输入的换行统一转为空格。键盘搜索键提交并收起键盘，搜索按钮同样提交去除首尾空白的文字，最大长度为 `MAX_CLASSIFY_TEXT_LENGTH`。空输入和识别期间禁用提交；设备来源下开始时只读取已经授权的定位。失败时在输入框附近显示友好错误，保留文字，成功后才清空。关闭面板会中止请求，晚到的结果不显示、不写入历史。

没有输入时，面板依次显示非空历史、BCRS 指南、可展开的分类浏览及底部的语言和关于入口。历史物品以状态色标记，清除按钮立即清空。四种语言可直接选择，切换立即作用于整个 App 并持久保存，面板保持打开。这是 App 内的语言入口。

文字、建议、分类、历史、BCRS 指南和拍照结果都使用同一个答案组件；交出答案时面板立即消失。历史保存完整结果，不保存照片。识别、建议和分类写入历史，重开历史及 BCRS 指南不新增记录。

## 关于

`AboutScreen` 从搜索面板底部进入，入口使用 `›` 表示应用内页面，以独立全屏页覆盖地图，关闭后回到仍然打开的面板。版本号和构建号从 `expo-application` 的 `nativeApplicationVersion` 与 `nativeBuildVersion` 读取，构建号不从 JS 配置推断。

页面包含独立项目与无隶属或背书关系的声明、各类回收点的数据发布方，以及地图、树木、步行路线的“© OpenStreetMap contributors”和 ODbL 署名。地图数据许可链接使用 core 的 `DATA_LICENSE_URL`。蓝色回收桶、电子废物以及 URA 规划区边界来源之后紧接 Singapore Open Data Licence 链接，使用 `OPEN_DATA_LICENCE_URL`；地区中文名注明 OpenStreetMap 来源，不展示数据更新日期。

AI 说明告知照片或文字发送至腾讯云，处理可能在新加坡以外进行，腾讯云最多保留 30 天并做内容审核。页面最后以“隐私与帮助”为节标题，提供隐私政策、支持及可选中复制的联系邮箱；邮箱行以次要文字显示“联系邮箱”标签。http/https 网页用 `expo-web-browser` 在 App 内打开，控件颜色为 `dark.accent`；展示期间忽略连点，关闭后保留原界面与状态。mailto 和 tel 交给系统，其他 scheme 拒绝打开；打开失败通过 `reportError` 上报。

## 相机与识别

全屏相机提供关闭按钮，只在相机已授权并启动时显示 72 大小的快门，不放取景文字。快门行左下角是至少 52×52 的“从相册选择”玻璃按钮，与快门垂直居中；只要没有照片就显示，包括相机权限被拒、未启用或拍照失败时。有照片或识别中隐藏。首次进入相机时申请系统权限。永久拒绝时说明原因，保留改用搜索栏的提示，并在说明下显示“打开设置”，进入本 App 的系统设置；关闭按钮返回首页。回到前台时重新读取相机权限，获准后恢复取景；若系统结束了进程，回到 App 后重新进入相机即可取景。

拍照或从 PHPicker 选择一张图片后，使用原照片铺满屏幕，并通过 `prepareImageForClassify` 压缩上传。相册只选图片、不多选、不裁剪，不申请相册权限，取消选择回到取景。图片先按原图渲染以应用 EXIF 方向，按渲染宽高计算最长边 2048 的目标尺寸，不放大，再按明确宽高缩放并保存为 `IMAGE_QUALITY` 的 base64 JPEG。编码后移除全部 APP1（Exif/XMP）段，不保留其中的 GPS；其余段（包括 ICC）和压缩图像数据逐字节保留，段结构无效或截断时终止处理。快门换为绿色进度环，识别期间不显示文字。进度为 `0.94 × (1 − exp(−elapsedMs / 3500))`，先快后慢且不达到 1；答案到达时卡片立刻出现，盖住进度环。设备来源且已经授权定位时，识别开始同时读取位置，不申请新权限。

取消会中止 `AbortController`，回到取景；即使结果晚到，也不会显示或写入历史。失败时保留照片，沿用友好错误文案；“重试”重新发送同一张照片，“回到取景”清除照片。

## 答案与去处

答案到达立即显示玻璃卡片。没有自动去处的答案默认展开，有自动去处的默认收起。顶部用宽而扁的箭头提示可以展开：收起时朝上，展开时朝下，点整个标题区直接切换，箭头本身对 VoiceOver 隐藏。点击“附近的蓝色回收桶”或“查找附近退还点”时先收起，再开始查找。收起时显示类型、物品名和最重要的一句：优先使用 `next_action.title`，其次是 `instruction.<channel>`，没有 channel 时显示原因。找到目标后，收起时也显示名称、非空地址和开放时间，以及距离；路线尚未取得时标明“直线”。

有 `next_action` 时，展开后显示动作说明与资格，标题沿用卡片主句，不重复显示，也不显示原因、去处说明、准备步骤或提示。没有 `next_action` 时，展开后可阅读低置信度提示、原因、去处说明、准备步骤和提示。BCRS 展示退还金额、四个步骤、适用及不适用范围和回收点数量；有害垃圾提供可拨打的热线。分享使用 `getResultShareText`。无内容的字段不占空行。

去处规则仅依据 mobile 的 channel 规则，Web 的规则不变：

| 答案 | 查找方式 | 附近类别 | 答案期间的点位图层 |
| --- | --- | --- | --- |
| BCRS | 自动 | return_point | return_point |
| 电子废物 | 自动 | ewaste | 无 |
| 电池 | 自动 | ewaste_battery | 无 |
| 灯管 | 自动 | lighting | 无 |
| 旧衣 | 自动 | textile | textile |
| 捐赠 | 自动，按物品映射筛选 | donation | 有物品筛选时无；无筛选时 donation |
| 大件垃圾 | 自动，Furniture 筛选，去处区域标明“考虑捐赠” | donation | 无 |
| 蓝色回收桶 | 点击“附近的蓝色回收桶” | blue_bin | 点击后 blue_bin |
| 不确定容器（check_container_type） | 点击“查找附近退还点” | return_point | 点击后 return_point |
| 一般垃圾、有害垃圾、其余空 channel | 保留照片或当前地图 | 不查询 | 保持首页选择 |

大件垃圾的去处区域在查找中、找到目标、附近没有及查询失败时，都以“考虑捐赠”标明这些是收家具的捐赠点。

设备来源需要去处时才申请尚未授权的定位；手动来源用地区中心查询 nearby，仍先 1 km、再 5 km。去处上方显示“以某地为中心”、“更换地区”和“改用我的位置”；更换后清除旧去处和路线并重新查找，切回设备后立即请求位置。手动来源在距离上方显示“起点：某地中心”，地图共同框住地区中心与去处。定位被拒、取不到或位于新加坡以外时，不查询 nearby，显示全岛与对应原因。5 km 内无目标时同样显示全岛和说明。只有能完全对应的点位图层会亮起，电子废物、电池、灯管及有物品筛选的捐赠不使用整层代替。查询失败显示说明及手动重试。

有照片时，照片通过 native driver 缩小、淡出约 700 ms，露出全岛，再用约 3 s 飞入目标的 3D 街区；没有照片时直接从当前视角飞往目标。落点至少 zoom 14、倾角 55°，卡片上方留出目标空间；能在街区视角内同时容纳用户和目标时展示两者，否则优先目标。减弱动态效果时不缩放照片、不飞行，直接切到落点，目的地脉冲保持静止。

“关闭”清除路线、距离气泡、目的地及答案图层覆盖，恢复此前的首页图层选择，地图保留当前位置。“再扫一个”同样清除地图中的答案数据，再直接打开相机。

## 步行路线

答案找到去处后立即请求 `POST /api/v2/route`，与相机飞行并行。原生地图通知飞行结束后显示发光路线及长度中点的距离气泡；路线晚到时等待响应，减弱动态效果时等待相机直接切到落点。路线使用接口原几何，地图不补画吸附点与用户或目标之间的空隙。

首页点位卡片和答案共用路线信息：成功后距离改为步行距离、约分钟数及步行单位，分钟向上取整且至少为 1。终点吸附距离不产生说明文字。VoiceOver 可读取步行距离和时间。卡片增加说明、重试或展开后，按实际布局高度重新取景，预留卡片上方的目标空间；首页使用整个底部控件的实测高度。

每个目标自动请求一次，只在用户点“重试”时再次请求。路线不可用时清除线和气泡，保留注明“直线”的距离。50 m 内无可步行路网或找不到路线时说明原因，不提供重试；限流使用等待时长文案，网络失败使用已有错误文案，均允许重试；服务忙、服务不可用、超时或响应违约时显示暂时无法生成路线并允许重试。权限或输入错误同样允许重试，并只上报错误码与 HTTP 状态。切换目标、位置来源、地区或离开当前结果会清除旧路线并取消请求，晚到结果不再显示或上报。点位卡片的直线距离按新起点重算。

路线请求在客户端边界用 `RouteRequestSchema` 校验，成功及错误响应分别用 v2 schema 解析。请求、响应、服务端错误文字与动态 schema 路径不进入错误消息、上报 context 或契约违例 issues；路线 URL 没有坐标查询参数。网络失败在 mobile 单独表示，不扩展 core 错误契约。

## 限流提示

识别、附近、点位和路线的 HTTP 429 统一映射为 `RATE_LIMITED`，包括 Cloudflare HTML 正文，不作为契约违约上报。`Retry-After` 只接受非负整数秒，其余写法和缺失都不提供等待时长，也不上报。

相机及相册识别、搜索识别、答案找去处和步行路线显示等待说明：1–59 秒显示秒数，60–3599 秒向上取整显示分钟，3600 秒起向上取整显示小时；缺失或 0 使用稍后再试的通用提示。路线仍可重试；地图点位仍显示原有的加载失败和“重试”。Web 文案和错误结构不变。

## 深色组件

`mobile/src/theme/dark.ts` 定义深色背景、烟熏玻璃底色和边框、正文和次要文字、绿色强调色和其上的深色内容，以及字号、控件尺寸、圆角和间距。搜索面板与关于页也使用这组 token 和玻璃组件。App 固定深色外观，启动画面和错误边界均使用 `dark.background`；错误页标题、正文和按钮也使用深色 token，系统控件固定深色。`colors.ts` 保留加载指示器的 `neaGreen`、错误页布局使用的 `spacing`、`radii` 和 `touch`。

`GlassPanel` 结合 Expo Blur 和深色覆盖层提供玻璃容器，`GlassButton` 提供带无障碍标签、选中状态和最小 52 高度的玻璃按钮。相机按钮为 72，正文为 16，说明文字为 14。玻璃底色覆盖率为 88%，最亮底图上也保持深色承载面。

## 无障碍

可操作控件的标签取自当前语言文案及数据名称；标签覆盖可见文字时包含这些文字。按钮、链接、开关和搜索框提供对应角色，卡片与面板的小标题使用 header。答案标题区读出类型、物品名和主句，展开或收起的操作说明放在 hint；答案标题区、分类、语言和图层入口以 expanded 表示展开状态。语言选项仅以原生语言名称作标签，以 selected 表示选中，并分别使用 en、zh-Hans、ms、ta 发音。进行中的快门、提交、重试、定位与取位置的步行路线控件提供 disabled、busy。装饰色点、图标、箭头和勾选标记不进入无障碍树。地图保持带 map.overview 标签的图像，不逐个暴露点位。

各入口交出的答案出现时，无障碍焦点移至答案标题区。搜索面板和关于页关闭后回到各自入口，地区面板取消关闭后回到打开它的按钮；选中地区后继续原操作，答案流程聚焦答案标题，首页聚焦更新后的位置提示或点位起点说明。搜索交出答案时直接聚焦答案。地区面板打开后聚焦标题。找到去处时播报名称和距离，路线取得后播报步行距离与约分钟数；答案卡和点位卡片使用相同规则。定位、去处、路线、限流、点位加载、搜索和相机的异步失败提示主动播报，接连的播报在 iOS 中排队，不依赖仅 Android 生效的 live region。

VoiceOver 双指 Z 字退出手势与关闭操作一致：搜索、关于和地区面板关闭；答案清除答案及路线；相机识别中取消识别，其他状态关闭；点位卡片关闭并清除路线。只靠无障碍控件可从拍照、相册或搜索进入答案，通过自动去处或已有的附近查找按钮取得去处，读到步行距离和分钟数。

文字随系统字号放大，正文、说明、按钮及输入框不设倍率上限。答案物品名、搜索和地区面板标题、关于页标题与 BinWhere、关于页节标题、错误页标题、点位名称的倍率上限为 2；地图上的 BCRS 胶囊和 OSM 署名同为 2。正文和按钮换行后容器随内容增高；首页底部内容仅在放大字号时可滚动，默认字号保留原有 View 与署名空白行的地图手势穿透。首页大字号底部、图层、相机提示和错误页的滚动区域不强制短内容竖向回弹；各面板和答案内容可滚动。字号倍率大于 1 时，答案底部操作、首页搜索与相机、搜索表单及底部入口、图层选项和面板标题栏纵向排列，文本获得整行宽度；英文、马来文和泰米尔文在词间换行，整行也放不下的长词才按系统规则断开。默认字号保留并排布局。点位地址完整换行；搜索历史标签保留单行截断。

减弱动态效果实时跟随系统设置：地图直接切到目标，照片不缩小或淡出，目的地脉冲静止，搜索面板和地区面板直接出现。关闭设置后恢复原有动画。
