# Security policy · 安全政策

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub private vulnerability reporting](https://github.com/ichoyb/binwhere-sg/security/advisories/new), or email ichoyb@gmail.com.

Include what you found, how to reproduce it and what an attacker could do with it.

In scope: the website and API at binwhere.sg and the BinWhere iPhone app. Please do not run automated scanners, load tests or large numbers of classification requests against binwhere.sg: classification calls a paid model, and the service is rate-limited.

## 报告漏洞

请不要在公开 Issue 中报告安全问题。请通过 GitHub 的[私密漏洞报告](https://github.com/ichoyb/binwhere-sg/security/advisories/new)提交，或发邮件至 ichoyb@gmail.com。

请说明发现的问题、复现步骤，以及攻击者可以借此做什么。

范围：binwhere.sg 网站与 API，以及 BinWhere iPhone App。请不要对 binwhere.sg 运行自动扫描、压力测试或大量识别请求：识别会调用付费模型，服务也设有限流。
